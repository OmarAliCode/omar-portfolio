# Purple vCard Freelancer Portfolio

A Next.js 15 freelancer portfolio inspired by the CodeWithSadee vCard personal portfolio layout.

## Run
npm install
npm run dev

Open http://localhost:3000

## Before publishing
Edit `app/page.js` and replace:
- YOUR_EMAIL@example.com
- +254 000 000 000
- YOUR_M-PESA_NUMBER
- WhatsApp number
- Social links
- Project details
- Profile initials/photo

## Features
- Purple/white-inspired vCard design
- Freelancer services
- Portfolio filtering
- Client comments stored in browser localStorage
- Service request form
- M-Pesa payment information section
- PayPal link
- Responsive mobile layout
